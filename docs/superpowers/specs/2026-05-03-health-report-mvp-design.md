# 健康管理体检报告 MVP 设计

## 目标

开发健康管理模块第一版，支持用户录入体检报告 OCR 文本，自动解析体检指标，并按报告批次和指标明细入库。

## 范围

- 支持手动粘贴 OCR 文本，不在第一版接真实 OCR 厂商。
- 保留可替换 `HealthOcrProvider` 接口，后续可接图片/PDF OCR。
- 存储报告批次、原始 OCR 文本、识别状态、指标字典和指标结果。
- 提供报告列表、报告详情和新建识别入口。
- 不提供医学诊断建议，仅展示原始值、单位、参考范围和异常标记。

## 数据模型

- `HealthReport`：报告批次，归属用户，记录标题、体检日期、来源文件名、OCR 文本和状态。
- `HealthMetricCatalog`：指标字典，按 `code` 唯一标识指标，记录名称、分类、默认单位和别名。
- `HealthMetricResult`：报告内的指标结果，关联报告和可选字典项，记录原始名称、值、单位、参考范围、异常标记和原始行文本。

## 数据流

1. 用户在 `/health/reports/new` 粘贴 OCR 文本。
2. 前端调用 Server Function 创建报告。
3. 服务层用 `ManualTextOcrProvider` 接收文本，再由解析器提取指标。
4. 服务层按指标名称维护字典项，并批量写入报告指标。
5. 用户在列表和详情页查看报告及指标。

## 验证

- 单元测试覆盖 OCR 文本解析、异常标记归一化和空文本校验。
- 运行路由生成与 TypeScript 检查，确认新增路由和 Prisma 类型可用。
